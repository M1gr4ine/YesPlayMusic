# Windows 小窗文字与展开行为

本功能使用现有播放器小窗，只在 Windows Tauri 桌面应用中启用。

- 小窗中的歌名、歌手、歌词和翻译不再允许左键选择文字。
- 从这些文字区域按住左键并移动，也可以拖动窗口；播放按钮、置顶按钮和进度条继续处理自己的操作。
- 双击文字、封面或空白区域进入播放队列。小窗位于当前屏幕下半部时向上展开，上半部时向下展开，尺寸限制在当前屏幕的工作区域内。
- 展开使用短暂的淡出和方向一致的弹出过渡。离开的小窗保持原有高度和上下边缘；队列内容使用位移、轻微缩放和透明度过渡，不逐帧调用原生窗口调整。
- 系统启用减少动态效果时，展开只保留较短的淡入。
- 展开后再缩窄队列窗口不会自动切换到完整歌词页；返回矮小窗后恢复原有自动歌词行为。
- 原生尺寸或位置调整失败时，尝试恢复原小窗位置和尺寸，并恢复原来的页面状态。

macOS、Linux 和浏览器的文字选择、拖动及展开路径保持原有行为。本 PR 不增加独立歌词窗口，也不包含 Windows 任务栏吸附或 QQ 音乐登录。
